# Invent-rio-Espa-o-Confinado
Inventário Espaço Confinado

PWA – Inventário de Espaços Confinados (NR-33)
📌 Descrição

Este projeto consiste no desenvolvimento de um Progressive Web App (PWA) para gerenciamento e inventário de espaços confinados, conforme diretrizes da NR‑33 – Segurança e Saúde nos Trabalhos em Espaços Confinados.

O objetivo da aplicação é facilitar o registro, organização e consulta de informações de espaços confinados dentro de uma empresa, permitindo que profissionais de Segurança do Trabalho tenham acesso rápido aos dados necessários para análise de risco, planejamento de atividades e controle operacional.

O sistema pode ser acessado via navegador ou instalado diretamente no celular, funcionando como aplicativo sem necessidade de instalação por loja (Play Store/App Store).

🎯 Objetivo do Projeto

O PWA foi desenvolvido para:

Criar um inventário digital de espaços confinados

Facilitar o cadastro e consulta de ambientes classificados como espaço confinado

Auxiliar na gestão de segurança conforme NR-33

Centralizar informações importantes para emissão de permissões de entrada

Permitir acesso rápido via dispositivos móveis em campo

👷 Público-Alvo

Técnicos em Segurança do Trabalho

Engenheiros de Segurança

Supervisores de Espaço Confinado

Empresas que possuem ambientes classificados como espaço confinado

⚙️ Funcionalidades
📋 Cadastro de Espaço Confinado

Permite registrar informações como:

Identificação do espaço

Localização

Tipo de espaço confinado

Dimensões

Riscos identificados

Atmosfera potencial

Equipamentos necessários

Classificação do risco

📍 Geolocalização

A aplicação permite registrar a localização do espaço confinado, facilitando a identificação dentro da empresa.

📸 Registro Fotográfico

Possibilidade de adicionar imagens do espaço confinado para documentação visual.
